# iooo-reuse/.github

Organization defaults. GitHub uses these files in every iooo-reuse repository that has no file of its own type.

- `.github/ISSUE_TEMPLATE/`: issue forms **Epik**, **Zadanie** and **Decyzja**. They set the org issue types Epic, Task
  and Decision. A Decision is answered with `/decide <option> <reason>` from the owner's account.

This repository is public by GitHub's rule for default community files. Keep it free of anything internal: no code,
data, hostnames or secrets.
